# 💣 지뢰찾기

9×9부터 16×30까지의 격자에서 지뢰를 피해 모든 안전한 칸을 여는 클래식 웹 지뢰찾기 게임입니다.
첫 좌클릭 칸에는 지뢰가 배치되지 않으며, 숫자는 주변 8칸에 있는 지뢰의 개수를 나타냅니다.

## 게임 소개

- **좌클릭**: 칸을 엽니다. 지뢰가 없는 빈 영역은 주변 숫자 칸까지 자동으로 확장됩니다.
- **우클릭**: 닫힌 칸에 깃발을 꽂거나 제거합니다.
- **승리**: 지뢰가 없는 모든 안전한 칸을 열면 승리합니다.
- **패배**: 지뢰를 좌클릭하면 게임이 종료되고 지뢰 위치가 공개됩니다.
- **첫 클릭 안전**: 첫 좌클릭 이후 지뢰가 무작위로 배치되며 첫 클릭 칸에는 지뢰가 없습니다.
- 상단에서 남은 지뢰 수와 경과 시간을 확인할 수 있고, 스마일 버튼으로 새 게임을 시작할 수 있습니다.

## 난이도

| 난이도 | 보드 크기 | 지뢰 수 |
| --- | ---: | ---: |
| 초급 | 9×9 | 10개 |
| 중급 | 16×16 | 40개 |
| 고급 | 16×30 | 99개 |

난이도를 변경하면 현재 게임이 초기화되고 선택한 크기의 새 보드가 생성됩니다.

## 어떻게 만들었나요

- 별도 빌드 도구나 외부 라이브러리 없이 **HTML, CSS, Vanilla JavaScript**로 구현했습니다.
- [index.html](./index.html)은 게임 화면의 구조와 접근성 속성을 담당합니다.
- [style.css](./style.css)는 전통적인 윈도우 지뢰찾기 스타일의 회색 패널, 입체적인 격자, 디지털 카운터를 담당합니다.
- [script.js](./script.js)는 난이도별 보드 생성, 첫 클릭 이후 지뢰 배치, 주변 지뢰 수 계산, 빈 영역 확장, 깃발, 타이머, 승패와 재시작을 관리합니다.
- PRD를 먼저 작성하고 구현 계획을 검토한 뒤 `prd` 브랜치에서 구현했으며, 이후 `dev` 브랜치에 병합했습니다.

## freeform 버전과 비교했을 때

freeform 버전은 여러 줄의 요구사항을 바탕으로 9×9 단일 난이도 게임을 빠르게 구현했습니다.
반면 이 버전은 PRD의 규칙을 기준으로 구현 범위를 명확히 정하고, 첫 클릭 안전 규칙과
난이도 선택 기능을 계획에 포함해 확장했습니다.

현재 `dev` 버전에는 다음과 같은 차이가 있습니다.

- 9×9 초급뿐 아니라 16×16 중급, 16×30 고급을 선택할 수 있습니다.
- 첫 클릭 시 선택한 칸을 제외하고 지뢰를 배치합니다.
- PRD에 맞춰 좌클릭과 우클릭을 기본 조작으로 사용합니다.
- 첨부된 전통적인 지뢰찾기 화면을 참고해 금속 패널, 디지털 숫자 카운터, 입체적인 칸 디자인을 적용했습니다.

기능 요구사항을 문서로 먼저 확인하고 구현할 수 있었기 때문에, `prd` 기반 버전을 최종 버전으로 선택했습니다.

## 실행 방법

별도 설치가 필요하지 않습니다. 저장소의 [index.html](./index.html)을 브라우저에서 열면 됩니다.

로컬 서버로 실행하려면 저장소 루트에서 다음 명령을 실행한 뒤
<http://localhost:8000>을 엽니다.

```bash
python -m http.server 8000
```

## 커스터마이징한 부분

- 전통적인 윈도우 지뢰찾기 스타일의 회색 금속 패널과 입체적인 보드 테두리
- `MINES`, `TIME` 디지털 카운터와 3자리 숫자 표시
- 초급·중급·고급 난이도 선택
- 중급·고급 보드를 위한 가로 스크롤
- 숫자별 색상, 깃발·지뢰·폭발 상태 표현
- 버튼, 상태 메시지, `aria-label`, `aria-live`를 활용한 기본 접근성 지원

자세한 실습 절차와 브랜치 흐름은 [guide.md](./guide.md)를 참고하세요.
