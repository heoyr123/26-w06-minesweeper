# 💣 지뢰찾기

9 × 9 격자에서 지뢰 10개를 피해 모든 안전한 칸을 여는 클래식 지뢰찾기 게임입니다.
첫 클릭한 칸과 주변에는 지뢰가 배치되지 않아 누구나 안전하게 게임을 시작할 수 있습니다.

## 게임 소개

- 좌클릭: 칸을 엽니다. 숫자는 주변 8칸에 있는 지뢰의 개수입니다.
- 우클릭: 칸에 깃발을 꽂거나 제거합니다.
- 휠 버튼 또는 좌·우 버튼 동시 클릭: 숫자와 주변 깃발 수가 맞으면 깃발이 없는 인접 칸을 엽니다.
- 지뢰를 누르면 게임이 끝나고, 모든 안전한 칸을 열면 승리합니다.
- 경과 시간과 남은 지뢰 수를 상단에서 확인할 수 있으며 `새 게임`으로 즉시 다시 시작할 수 있습니다.

## 어떻게 만들었나요

- 별도 빌드 도구 없이 HTML, CSS, Vanilla JavaScript로 구현했습니다.
- `script.js`에서 지뢰 배치, 주변 지뢰 수 계산, 빈 영역 확장, 타이머, 승패 상태를 관리합니다.
- 버튼 기반 격자와 `aria-label`, `aria-live`를 사용해 키보드와 스크린 리더에서도 상태를 확인할 수 있습니다.

## freeform 버전과 비교했을 때

이번 버전은 freeform 프롬프트의 핵심 요구사항을 충실히 구현하면서, 첫 클릭 안전 규칙과
반응형 레이아웃, 접근성 레이블, 승패 메시지까지 추가했습니다. 게임 로직과 스타일을
파일별로 분리해 수정과 재사용이 쉬운 구성을 선택했습니다.

## 실행 방법

별도 설치가 필요하지 않습니다. 저장소에서 [index.html](./index.html)을 브라우저로 열면 됩니다.
로컬 서버가 필요하다면 저장소 루트에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```bash
python -m http.server 8000
```

## 커스터마이징한 부분

- 어두운 배경과 라임 포인트를 사용한 미니멀한 게임 화면을 구성했습니다.
- 화면 폭에 맞춰 9 × 9 격자 크기가 조정되는 반응형 UI를 적용했습니다.
- 첫 클릭 주변을 포함한 안전 영역 보장, 999초 제한 타이머, 깃발 개수 제한을 추가했습니다.
